# قواعد بناء قوالب واتساب (Meta WhatsApp Templates)

عند بناء أي قالب رسالة جديد، اتبع هذا الهيكل:

1. تحية مختصرة بالسعودي (مثال: "هلا بك")
2. جسم الرسالة بمتغيرات بصيغة {{1}}، {{2}} (اسم المريض، التاريخ)
3. لا يتجاوز القالب 1024 حرف (حد Meta الأقصى)
4. يُذكر دائماً اسم العيادة بأول الرسالة
5. التسعير المرتبط بأي خدمة يُذكر بالريال السعودي (SAR) فقط
